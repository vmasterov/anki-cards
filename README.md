# anki-cards

Карточки Anki для постоянного изучения и поддержания знаний по фронтенду
и смежным темам.

## Ссылки

- **AnkiWeb** — облако, куда синхронизируются карточки:
  [ankiweb.net/decks](https://ankiweb.net/decks). Там же можно повторять
  в браузере без установленного приложения (нужен интернет).
- **Репозиторий** — исходники карточек:
  [github.com/vmasterov/anki-cards](https://github.com/vmasterov/anki-cards).

## Структура

```
.
├── RULES.md       регламент составления карточек
├── HANDOFF.md     состояние проекта, статусы тем
├── decks/         колоды, по папке на тему
│   └── <topic>/
│       ├── sc.csv      один правильный вариант
│       ├── mc.csv      несколько правильных
│       ├── kprim.csv   четыре утверждения верно/неверно
│       ├── cloze.csv   пропуски
│       ├── type.csv    ввод ответа с клавиатуры
│       └── basic.csv   открытый ответ
└── tools/
    ├── check.py           запуск проверки
    ├── deck_io.py         чтение CSV-колод
    ├── notetypes.py       выбор правил по типу заметки из #notetype
    ├── validators.py      общие правила и правила AllInOne
    ├── rules_two_field.py правила для Простая, ввода ответа и пропусков
    └── deck_index.py      индекс вопросов по всем колодам
```

## Подготовка Anki

Делается один раз. Порядок важен: дополнение ставится только в настольной
версии, и именно она создаёт нужный тип карточек.

### 1. Anki на Mac

Скачать с официального сайта **apps.ankiweb.net** — не из App Store, там
платные подделки с похожими названиями. Для процессоров M1–M4 нужен файл
`mac-apple.dmg`, для Intel — `mac-intel.dmg`.

### 2. Аккаунт AnkiWeb

Нажать **Sync** в Anki, в окне входа перейти по ссылке регистрации, завести
бесплатный аккаунт и подтвердить почту. Аккаунт нужен для переноса карточек
на телефон.

### 3. Дополнение Multiple Choice

*Tools → Add-ons → Get Add-ons*, вставить код `1566095810`, перезапустить
Anki. Тип заметки `AllInOne (kprim, mc, sc)` появится сам при первом запуске
после установки — вручную создавать его не нужно.

Проверить поля: *Tools → Manage Note Types → выбрать тип → Fields*. Должно
быть 11 полей в порядке `Question, Title, QType (0=kprim,1=mc,2=sc),
Q_1 … Q_5, Answers, Sources, Extra 1`. Если порядок отличается, скажи
модели — она подстроит генерацию под фактический порядок.

### 4. FSRS

В настройках любой колоды (шестерёнка → *Options*) включить **FSRS** —
современный алгоритм планирования вместо старого SM-2. Для долгой базы
он точнее предсказывает забывание и экономит время на повторениях.

### 5. AnkiDroid на телефоне

Поставить **AnkiDroid** из Google Play или F-Droid (бесплатно, издатель
AnkiDroid Open Source Team). Открыть боковое меню, нажать синхронизацию,
войти под тем же аккаунтом AnkiWeb. Карточки приедут вместе с шаблоном —
дополнение на телефоне не нужно.

Уведомления: *Настройки → Уведомления*, задать время напоминания и
минимальное число карточек для срабатывания. Отдельно проверить, что Android
не ограничивает приложению фоновую работу (настройки батареи → без
ограничений), иначе напоминания будут приходить с опозданием.

### 6. Первая синхронизация

При первой синхронизации Anki спросит, какую сторону считать главной.
Выбрать **Upload to AnkiWeb** — в облаке пока пусто. Дальше синхронизация
идёт автоматически в обе стороны.

## Проверка перед импортом

```bash
python3 tools/check.py             # все колоды
python3 tools/check.py decks/git   # одна тема
```

Скрипт проверяет число колонок, наличие и уникальность тега-идентификатора,
совпадение GUID с ним и дубли вопросов по всем колодам в `decks/`. Для
AllInOne — ещё QType и соответствие маски ответов числу вариантов, для
`Простая` — непустой ответ, для пропусков — наличие `{{c1::…}}`. Ненулевой код возврата означает, что импортировать
файл нельзя.

## Импорт карточек

1. *File → Import*, выбрать нужный CSV.
2. Разделитель, тип заметки, HTML и колонка тегов берутся из служебной шапки
   файла автоматически. Колода — из строки `#deck:`, она будет создана,
   если её ещё нет.
3. Включить **Update existing notes**, чтобы правки обновляли карточки,
   а не создавали дубли. Anki сверяет первое поле — текст вопроса.
4. Проверить в окне импорта, что столбцы сопоставлены с полями правильно,
   и нажать **Import**.
5. Нажать **Sync**, затем синхронизировать телефон.

### Если что-то выглядит не так

- **Варианты ответа не кликаются, видна голая разметка** — файл
  импортирован не тем типом заметки. Удалить импортированные заметки
  (*Browse* → фильтр по тегу партии) и повторить импорт.
- **Поля разъехались** — порядок полей в твоём типе заметки отличается от
  ожидаемого. Сверить по пункту 3 подготовки и сообщить модели.
- **Теория под спойлером не раскрывается** — проверить, что при импорте был
  включён HTML (строка `#html:true` в шапке файла).
- **Карточки задвоились** — импорт прошёл без «Update existing notes» либо
  вопрос был перефразирован. Лишние удаляются через *Browse* по тегу `id-*`.

## Как учить

Отметить варианты (мышью или клавишами 1–4), нажать **Show Answer**
(пробел), затем оценить ответ:

- **Again** — не вспомнил, карточка вернётся через несколько минут;
- **Hard** — вспомнил с трудом, интервал почти не вырастет;
- **Good** — вспомнил нормально, обычный вариант;
- **Easy** — ответ очевиден, карточка уйдёт надолго.

Оценивать честно: сплошные Easy приведут к забыванию, сплошные Hard —
к завалу повторений.
